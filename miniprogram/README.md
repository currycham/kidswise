# Waywise 家长端小程序

微信原生小程序，AppID `wxa7e9bd6d8398bc8c`。只读为主：家长在手机上「看」，创建主题在电脑上（软件文档 0.3）。

| 页面 | 内容 |
|---|---|
| 今天 `pages/index` | 孩子的一句原话、安全提醒、聊了几分钟 / 几句 / 几个词、今天碰到的词 |
| 对话记录 `pages/history` | 按天翻，完整逐句 |
| 成长 `pages/growth` | 这周会说的词、听过的词（三档掌握度） |
| 我的主题 `pages/themes` | 十个主题，点选切换孩子正在学的主题 |
| 孩子信息 `pages/child` | 扫码 / 输入设备码绑定设备，改昵称和年龄 |

接口：`https://api.waywise.tech/api`，说明见 [agent/API.md](../agent/API.md)。
登录用 `wx.login` 的 code 由服务端换 openid，AppSecret 不在小程序里。

## 本地预览

1. 微信开发者工具 → 导入项目 → 选这个 `miniprogram` 目录（AppID 会自动读出）
2. 编译后在模拟器里点「绑定设备」，扫码时选一张设备码二维码图片（demo 阶段二维码内容就是设备码）
3. 手机预览：工具栏「预览」扫码；给别人看用「上传」后在后台设为体验版（不用提审）
