## 系统实际怎么处理数据（2026-10-04 核实）

| 数据 | 是否保存 | 在哪 | 核实方式 |
|---|---|---|---|
| 孩子的声音 | **不保存**：识别成文字后删除录音 | 识别时发给阿里云百炼（语音识别） | 服务器配置 `delete_audio: true`，临时目录里没有录音文件 |
| 摄像头照片 | **不保存**：只用于当下这一次理解 | 理解时发给阿里云百炼（视觉模型） | 照片只在内存里处理（`vision_handler.py`），不落盘 |
| 对话文字（孩子说的、木米说的） | 保存 | 我们的服务器（腾讯云，国内） | `message` 表 |
| 孩子问过的问题、记下的事、没做完的事 | 保存 | 同上 | `child_question` / `memory_fact` / `follow_up` 表 |
| 英文词掌握情况、好奇心周报 | 保存 | 同上 | `word_progress` / `weekly_report` 表 |
| 孩子昵称、年龄、设备号 | 保存 | 同上 | `child` / `device` 表 |
| 家长的微信身份（openid）、教育理念、和顾问的对话 | 保存 | 同上 | `parent` / `family_profile` / `advisor_message` 表 |
| 安全事件（受伤、走失等求助） | 保存，并通知家长 | 同上 | `safety_event` 表 |

**处理数据的第三方：** 阿里云百炼（语音识别、对话模型、视觉模型）、火山引擎（语音合成；对话模型的备用通道）、
腾讯云（服务器）、微信（家长登录）。
